# 🎮 GTA 6 Clipper: מסרטון ארוך לרילס וטיקטוק

נותנים לו סרטון גיימפליי ארוך של GTA 6, קובץ או קישור ליוטיוב, והוא:

1. **מוצא לבד את הרגעים החמים**: קפיצות בווליום (יריות, פיצוצים, תאונות, צעקות) והרבה תנועה על המסך.
2. **חותך כל רגע לקליפ אנכי 1080×1920**, שמתחיל שנייה וחצי לפני האקשן כדי לתפוס את הצופה מהר.
3. **מוסיף לכל קליפ**: כותרת "הוק" למעלה, שם המשתמש שלך, פס התקדמות צהוב, ווליום מכוון לרשתות, ואם רוצים גם כתוביות מהקריינות שלך.
4. **מכין דף סקירה** (`index.html`) לצפייה בכל הקליפים, עם כיתוב והאשטגים מוכנים להעתקה.

כל קליפ מוכן להעלאה כמו שהוא לטיקטוק, לאינסטגרם רילס וליוטיוב שורטס.

---

## התקנה (פעם אחת)

**Mac:**
```bash
brew install ffmpeg python
cd gta6-clips
pip3 install -r requirements.txt
```

**Windows:** מתקינים [Python](https://www.python.org/downloads/) ו-[ffmpeg](https://www.gyan.dev/ffmpeg/builds/) (ומוסיפים אותו ל-PATH), ואז `pip install -r requirements.txt`.

> הכתוביות (`--subs`) צריכות גם `pip3 install faster-whisper`. בפעם הראשונה הוא מוריד מודל דיבור של כמה מאות MB.

## שימוש

```bash
# הכי פשוט: קישור ליוטיוב, 8 קליפים של עד 30 שניות
python3 clipper.py "https://youtu.be/XXXXXXXXXXX" --handle @הערוץ_שלך

# מקובץ שכבר יש לך במחשב
python3 clipper.py "~/Movies/gta6 stream.mp4" --handle @הערוץ_שלך

# 12 קליפים של עד 45 שניות לרילס
python3 clipper.py video.mp4 -n 12 --len 45 --platform reels

# אתה יודע בדיוק איפה הרגע? חותכים ביד
python3 clipper.py video.mp4 --at 12:30-12:58,1:02:00-1:02:40

# כתוביות מהקריינות שלך (עברית)
python3 clipper.py video.mp4 --subs --lang he

# כותרות משלך (מתחלפות בין הקליפים)
python3 clipper.py video.mp4 --title "ככה בורחים מהמשטרה|חכו לסוף...|לא תאמינו"

# קודם רק לראות אילו רגעים הוא מצא, בלי לרנדר
python3 clipper.py video.mp4 --analyze-only
```

### שלושה סגנונות מסך (`--style`)

| סגנון | איך זה נראה | מתי |
|---|---|---|
| `blur` (ברירת מחדל) | כל המסך של המשחק באמצע, ומאחוריו אותו וידאו מטושטש | רואים הכל, גם את המפה ואת ה-HUD |
| `square` | ריבוע מוגדל ממרכז המסך | האקשן גדול יותר, ועדיין יש מקום לכותרת |
| `full` | חיתוך 9:16 שממלא את כל המסך | מקסימום אקשן, בעיקר כשהדמות במרכז |

ב-`square` וב-`full` אפשר להזיז את החיתוך לצדדים עם `--crop-x` (0 = שמאל, 0.5 = מרכז, 1 = ימין).

## מה יוצא

```
out/<שם הסרטון>/
├── clip_01.mp4 … clip_08.mp4   ← הקליפים, מהחזק לחלש
├── index.html                   ← דף סקירה: צפייה, גרף "חום" של כל הסרטון, כיתובים להעתקה
├── captions.txt                 ← כיתוב והאשטגים לכל קליפ
├── clips.json                   ← זמני החיתוך (מקור + התחלה + סוף)
└── analysis.json                ← הניתוח נשמר, אז הרצה שנייה על אותו סרטון מהירה
```

אם הגיע מיוטיוב, בדף הסקירה יש לכל קליפ קישור לרגע המדויק בסרטון המקורי.

## כל האפשרויות

| אפשרות | ברירת מחדל | מה |
|---|---|---|
| `-n`, `--count` | 8 | כמה קליפים |
| `--len` | 30 | אורך מקסימלי בשניות. קליפ מתקצר לבד אם הסוף שלו משעמם |
| `--min` | 12 | אורך מינימלי |
| `--platform` | tiktok | `tiktok` / `reels` / `shorts`. מגביל את האורך (60/90/60) |
| `--at` | | חיתוך ידני: `12:30` (אז האורך הוא `--len`) או טווח `12:30-12:58`, מופרדים בפסיק |
| `--style` | blur | `blur` / `square` / `full` |
| `--title` | | כותרת קבועה. כמה כותרות עם `\|` מתחלפות |
| `--auto-title` | he | שפת הכותרות האוטומטיות: `he` / `en` / `none` |
| `--title-secs` | 0 | כמה שניות הכותרת מוצגת (0 = כל הקליפ) |
| `--handle` | | השם שלך על המסך, למשל `@gta6_il` |
| `--subs` | כבוי | כתוביות מהדיבור (צריך faster-whisper) |
| `--lang` | זיהוי אוטומטי | שפת הדיבור לכתוביות: `he` / `en` |
| `--whisper-model` | small | `tiny` (מהיר) עד `large-v3` (מדויק). לעברית עדיף `medium` ומעלה |
| `--font` | Arial | גופן הטקסט (חייב לתמוך בעברית) |
| `--no-bar` | | בלי פס ההתקדמות |
| `--fps` | כמו המקור, עד 60 | קצב פריימים |
| `--crf` | 20 | איכות. נמוך = איכותי יותר וכבד יותר |
| `--jobs` | 2 | כמה קליפים מרנדרים במקביל |
| `--audio-only` | | ניתוח מהיר לפי קול בלבד (טוב לסרטונים של כמה שעות) |
| `--skip-start` / `--skip-end` | 5 | שניות להתעלם מהן בהתחלה ובסוף (אינטרו ואאוטרו) |
| `-o`, `--out` | out | תיקיית הפלט |
| `--analyze-only` | | רק להציג את הרגעים שנמצאו |
| `--reanalyze` | | להריץ שוב את הניתוח ולא להשתמש בשמור |

## איך הוא בוחר רגעים

- **קול:** לכל חצי שנייה מחושב הווליום, ומושווה לחצי הדקה שמסביב. "חם" זה רגע שקופץ מעל הרקע שלו, ולא סתם קטע רועש. ככה נהיגה ארוכה עם מוזיקה חזקה לא נבחרת, אבל פיצוץ באמצעה כן.
- **תנועה:** כמה התמונה משתנה בין פריימים (מרדפים, קרבות, תאונות).
- **ציון:** 65% קול ו-35% תנועה. בוחרים את החלונות עם הציון הכי גבוה, בלי חפיפה ביניהם.
- **הוק:** הקליפ מתחיל שנייה וחצי לפני השיא הראשון, ונחתך אחרי שהאקשן נגמר.
- רגעים חלשים מדי בהשוואה לטוב ביותר לא נכנסים, כך שבסרטון שקט יוצאים פחות קליפים במקום קליפים משעממים.

הניתוח של סרטון של שעה לוקח בערך 2 עד 5 דקות במחשב רגיל, ועם `--audio-only` הרבה פחות.

## טיפים

- **מעלים מעט אבל כל יום.** 8 קליפים מסרטון אחד זה שבוע של תוכן. לא להעלות הכל באותו יום.
- **3 השניות הראשונות קובעות.** אם קליפ לא מתחיל באקשן, חותכים אותו שוב ביד עם `--at` ומתחילים מאוחר יותר.
- **כותרת שאלה או "חכו לסוף"** מחזיקה צופים עד הסוף, וזה מה שהאלגוריתם מודד.
- **סדרות:** "חלק 1", "חלק 2" עם `--title` גורמים לאנשים להיכנס לפרופיל.
